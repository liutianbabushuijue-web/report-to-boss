# 话术模板速查

## 按汇报环节

| 环节 | 话术骨架 |
|------|----------|
| 结论开场 | 「汇报一个结论：……，需要您……。」 |
| 数据支撑 | 「具体数据是：……（量化）。」 |
| 给判断 | 「基于以上数据，我认为……，具体方案是……；如果不做，……会……。」 |
| 请示（带方案） | 「关于 X，我有两个方案：A 是……，B 是……，我倾向 A，因为……，想请您定。」 |
| 报风险 | 「有个风险第一时间同步：……，原因是……，我已做……来补救；如果您愿意给资源，我需要……。」 |
| 收尾确认 | 「以上是我的判断，您看方向对不对？需要我优先推进哪块？」 |

## 量化对照（把形容词换成数字）

| 模糊说法 | 量化说法 |
|----------|----------|
| 客户很满意 | 客户续费率从 80% 升到 90% |
| 优化了代码 | 系统响应时间从 3s 降到 0.5s |
| 进度不错 | 完成 80%，较计划超前 2 天 |
| 转化有点提升 | 转化率环比 +15% |
| 大概能按时 | 按当前速度，6 月 10 日可交付，风险点只有一个 |

## 完整示例（照抄结构）

> 「我认为 A 项目需要调整方向。」
>
> 「数据上，本阶段转化率环比下降 12%；事实上，B 环节人手只有 1 人、已连续三周加班；案例上，去年同类项目不调整时延期了 4 周。」
>
> 「基于以上数据，我认为 A 项目需要调整方向，具体方案是把 B 环节加到 3 人、C 环节提前一周启动；我的判断是，如果不做这个调整，下阶段交付至少延迟两周。您看行不行？」
