# 反例对照（黑名单详解）

## 黑名单四项

| 黑名单 | 错误示例 | 正确示例 |
|--------|----------|----------|
| 只说问题不给方案 | 「效率还是低。」 | 「效率还是低，我建议 B 环节加到 3 人、C 环节提前一周启动，您看行不行？」 |
| 模糊词 | 「客户大概挺满意的。」 | 「客户续费率从 80% 升到 90%。」 |
| 隐瞒坏消息 | （憋到最后 / 报喜不报忧） | 「第一时间：X 出问题了，原因是……，我准备做……补救，需要……资源。」 |
| 让领导猜 | 「我优化了代码。」 | 「系统响应时间从 3s 降到 0.5s，直接支撑了目标进度。」 |

## 四维度翻译表（把"我做了什么"翻译成"领导关心什么"）

| 领导关心的维度 | 你的话怎么翻译 |
|----------------|----------------|
| 目标 | 完成 X%，距目标还差 Y |
| 进度 | 超前 / 正常 / 滞后 N 天，原因是什么 |
| 风险 | 可能延迟 X，我已做的应对是 Y |
| 资源 | 需要 Z 资源 / 请您拍板某决策 |

## 黑名单扩展项（v1.1.1 新增）

| 黑名单 | 错误示例 | 正确做法 |
|--------|----------|----------|
| 相似对象混为一谈 | 把「素养联盟」写成「素养大会」（或反过来） | 先确认是同一对象还是两个对象；不同对象各自保持写法并登记术语表 |
| 寒暄铺垫过长 | 「各位老师好！向大家汇报一下工作呀，最近我们做了很多……」 | 第一句给结论：「汇报一个结论：推广已有 X 个学院群转发，请老师们继续扩散。」寒暄最多一句 |
| 表情/语气词过载 | 「上架啦~[Hey][加油]」 | 书面汇报不用；群消息可保留自然语气，但不淹没信息 |

## 心态对照

| 错误定位 | 正确定位 |
|----------|----------|
| 我是老板的手脚，报完就算交差 | 我是老板的外脑，交付判断，让他只需点头 |
| 把"勤奋"当价值（我加了很久班） | 把"判断和结果"当价值（我判断这样能达标） |
| 被动被追问才汇报 | 关键节点主动汇报，平时不刷存在感 |
