# SBL 战略商业领袖视角（ACCA）—— 汇报框架补充

> ACCA Strategic Business Leader（SBL，战略商业领袖）把「向上汇报」当作职业能力来考：其高频题型就是给董事会写 briefing note，专业技能分里 Communication（沟通）是核心打分项。本文件提炼 SBL 与「向上级汇报」直接相关的框架，与 SKILL.md 的三段式互补。

## Briefing Note 结构（书面汇报标准格式，可与口头三段式互转）

1. **Purpose 目的**：一句话——这份材料要让决策者做什么决定；
2. **Background / Key issues 背景与关键事项**；
3. **Analysis 分析**：数据 + 事实 + 模型；
4. **Options 选项**：2–3 个可行方案；
5. **Recommendation 建议**：明确推荐一个 + 理由；
6. **Risks 风险与影响**：推荐方案的风险 + 应对；
7. **Next steps 下一步**：需要决策者批准什么。

> 对应关系：口头三段式（结论→支撑→判断）是 briefing note 的压缩版；写书面材料时展开成上面 7 段即可。

## SAF 方案评估法（给「让领导做选择题」加分）

给领导 2–3 个方案时，每个方案用三个词评估：

| 维度 | 问题 |
|------|------|
| Suitability 适合性 | 方案是否符合战略方向？ |
| Acceptability 可接受性 | 利益相关者能否接受（风险 / 回报）？ |
| Feasibility 可行性 | 资源、能力、时间是否可行？ |

## 委托代理视角（为什么「告知」不够的理论版）

- 董事会 / 上级是**委托人**，执行者 / 下级是**代理人**，天然信息不对称。
- 汇报的本质是**缩小信息不对称**：只告知 = 把信息丢回去让委托人自己加工；交付判断 = 替委托人把认知加工成决策——这正是「你是老板的外脑」的理论版本。

## 领导风格理论（辅助「按领导风格汇报」）

| 风格 | 特点 | 汇报侧重 |
|------|------|---------|
| 变革型领导 | 愿景驱动 | 多讲意义、方向与长期价值 |
| 交易型领导 | 绩效交换 | 多讲指标、兑现与奖罚对应 |
| 情境领导 | 按下属成熟度调整放权 | 对应结果型 / 细节型 / 放权型领导分类 |

## 风险应对 TARA（报坏消息的结构化）

- **T**ransfer 转移 / **A**void 规避 / **R**educe 减少 / **A**ccept 接受
- 报坏消息 = 风险事实 + 影响量化 + 已采取的应对（TARA 四选一）+ 需要的资源。与 SKILL.md 黑名单第 3 条（原因 + 补救 + 要资源）同构。
