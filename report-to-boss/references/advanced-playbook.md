# 进阶手册（分场景 / 分对象 / 述职 / 载体）

> 本文件是对 SKILL.md 核心的补充，服务于同一灵魂（交付判断），不冲突、不喧宾夺主。

## 分对象汇报（先判断「听的人是谁」）

| 对象 | 关心什么 | 汇报重点 |
|------|---------|---------|
| 直属领导 | 听内容 | 问题 + 你的方案 + 用方案后的效果（配数据） |
| 上级领导 | 看规划 | 重点结果 + 未来目标 + 可执行方案；忌流水账 |
| 平级 / 同事 | 抄方法 | 可复用的方法论与经验 |

## 先想清楚本次汇报的目的（三选一）

1. **获得表扬**：突出成果与亮点，全部可量化。
2. **争取资源**：突出投入产出与缺口，明确要什么资源、给资源后能得到什么。
3. **得到体谅**：突出困难与客观约束 + 你已尽的努力 + 需要什么支持。

> 同一份汇报主目的只有一个，别混。

## 述职内容配比（参考）

| 模块 | 占比 | 要点 |
|------|------|------|
| 业绩回顾 | 40% | 大小成果往量化上列 |
| 方法经验 | 30% | 最重要：可复用的方法论，领导眼里「能帮公司挣钱」 |
| 问题分析 | 15% | 不逃避；把坑分析清楚、让团队不再踩，「帮公司省钱」 |
| 未来规划 | 15% | 点到为止，方向模糊即可，不是项目计划书 |

## 自我定位（述职前先对号入座）

| 定位 | 策略 |
|------|------|
| 优等生 | 突出信心与成果 |
| 上进生 | 突出专业度，委婉要资源（「再给点支持我就能更好」） |
| 后进生 | 突出学习与成长曲线，让领导觉得「还能抢救」 |

## 载体技巧（PPT / 材料）

- **字不如表、表不如图**：能用图不用表，能用表不用字。
- PPT 分两种：「用来看的」（文字细）与「用来讲的」（文字只占约 30%）。汇报用后者：听众 10 秒看完关键词，全神贯注听你讲。
- **练习**：烂熟于胸是克服紧张的唯一捷径；表现力（语调 / 表情 / 肢体）决定能否被记住。

## 情绪原则

- 汇报就事论事，不夹杂个人情绪、不诉苦、不抱怨；报完按自己的节奏推进，别被带偏。

## 提升汇报能力的方法

- 多主动汇报（正式 + 非正式），根据领导反馈不断调整和总结。汇报能力是练出来的，不是看出来的。
